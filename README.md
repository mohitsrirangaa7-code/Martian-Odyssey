# Martian-Odyssey


# DATA STRUCTURE

*Jezero Explorer — Data Architecture*

Layer 1 — Base map and terrain
Core
HiRISE, CTX, MOLA, HRSC, derived DEMs
Elevation, slope, surface roughness, obstacles and terrain morphology.


Layer 2 — Geology and mineralogy
Core
USGS geological map, CRISM, SuperCam, PIXL, SHERLOC
Rock formations, mineral deposits, geological boundaries and scientific targets.


Layer 3 — Thermal and atmospheric
Core
THEMIS, MEDA, MCS, MARCI
Temperature, dust, atmospheric pressure, wind and thermal characteristics.


Layer 4 — Human safety
Core
Radiation models, solar activity, derived terrain hazards
Radiation exposure estimates, environmental warnings and relative route risk.


Layer 5 — Scientific exploration
Core
Mastcam-Z, SuperCam, PIXL, SHERLOC, RIMFAX, rover traverse and PLACES
Observation locations, sample sites, scientific targets and ground-level imagery.


Layer 6 — Mission planning
Derived
Derived terrain layers + mission constraints
Route planning, walking difficulty, estimated travel distance, hazards and scientific value.
